# CPP Module 08

> Templated containers, iterators and algorithms.

## What's inside

- STL containers and algorithms
- easyfind
- Span
- MutantStack (iterable stack)

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
